鬼泣5 切人Mod 正式版 release-44

安装与启动
1. 解压整个压缩包，运行 DMC5SwitchLauncher.exe。
2. 选择包含 DevilMayCry5.exe 的游戏目录。
3. 退出游戏，点击“安装 / 更新 Mod”。
4. 设置“下一位”“上一位”，点击“保存并启动游戏”。

新安装默认使用 F17 / F18，可改为 F5 / F6 等两个不同按键。
已有安装保留原按键。
手柄可开启“按住挑衅 + LB 上一位 / RB 下一位”；背键映射需与启动器所选键位一致。
游戏运行中保存按键设置，下次启动生效。

功能
在尼禄、但丁、维吉尔之间切换；备用角色提前加载。
切换时同步当前位置，并清零速度及惯性；切入角色以人形恢复。
三人的血量、魔人槽、真魔人槽、装备及血宫换层状态分别维护。
正常血宫换层时，主控暂时缺失不再清除已提交的角色与库存快照。
切入时随机播放该角色已加载的原生挑衅语音；多条可选时避免连续重复。
三名角色分别计时，同一角色三秒内最多播放一次切人挑衅；换层不重置冷却。
后台存活角色每两秒回复一格血，保留原有后台回魔；暂停与加载期间不计时。
尼禄空机械手自动补给；但丁摩托使用已加载的红色 Cavaliere R 资源。
暂停菜单 SKILL LIST 跟随当前操控角色显示技能，保留原生技能说明及预览。
原生 V 关卡不启用三人切换。
包含窗口消息链修复，避免已注册窗口钩子被反复拆装形成循环。

正式版内容
仅包含安装器、使用说明和 REFramework 许可证。
安装器内嵌15个运行模块和加载器，不包含本 Mod 的 F8 快照、调试面板、
采样脚本、热重载、测试程序、调查记录或个人存档。
窗口消息修复基于 REFramework 同一提交的本地源码重编译，采用 MIT 许可证。

更新与卸载
更新前退出游戏，再点击“安装 / 更新 Mod”。
安装器保留已有加载器，不替换来源不明的其他代理 DLL；新安装使用内置修复版。
退出游戏后点击“卸载 Mod”。按键配置和备份保留；其他 Mod 文件不受影响。
安装备份位于游戏目录 .dmc5-character-switch/history/。
不修改游戏 EXE、PAK 或存档。更换电脑后需重新选择游戏目录。
启动器需要 Windows .NET Framework 4.x。

已知情况
维吉尔环绕幻影剑在切出后仍可能留场，按当前约定保留现状。
窗口消息修复后用户暂未复现菜单闪退；长时间稳定性仍需持续使用确认。
