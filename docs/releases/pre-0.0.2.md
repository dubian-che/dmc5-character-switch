# pre-0.0.2 · 完整安装与加载器兼容检查

内部构建 release-48-complete-install。候选安装包，尚待远端环境实机复测。

## 修改

- 安装时先备份已有同名文件，完整部署 15 个正式 Lua 脚本和内置验证版本的 dinput8.dll。
- 更新时修复缺失或被改动的本 Mod 文件，当前内容保留在历史备份中。
- 安装结束逐项核对文件 SHA-256；校验失败按事务回滚，不显示安装成功。
- 启动前再次校验完整安装，阻止脚本或加载器被替换后的不一致启动。
- 缺少 thread.get_hook_storage 时，在加载任何游戏模块和注册钩子前停止切人初始化，记录明确错误。
- 卸载时按归属恢复安装前的加载器；对无原始加载器、后来增加其他插件的情况保留共用加载器。

## 安装

完全退出游戏后解压运行 DMC5SwitchLauncher.exe，选择游戏目录并点击安装 / 更新。
已有 dinput8.dll 会被备份并更新为内置版本；其他插件文件不被删除。原有插件与更新后加载器的兼容性仍需实机测试。
按键设置和存档不变。备份位于游戏目录 .dmc5-character-switch/history/。

## 文件

- DMC5CharacterSwitch-pre-0.0.2.zip：普通版，无诊断记录器。
- DMC5CharacterSwitch-pre-0.0.2-diagnostics.zip：相同 Mod 加可选只读记录和最近 30 分钟 ZIP 导出。
- SHA256SUMS.txt：安装包校验值。

## 验证范围

49 项离线检查，另含诊断导出自测。新增旧加载器升级、15 模块逐个缺失/损坏检测、修改文件备份修复、完整归属校验、DLL 写入后失败回滚、最终校验失败回滚及不支持 thread 接口时零钩子/零模块加载测试。

本版针对已捕获的加载器接口缺失问题。用户通过修改器设置的机械手库存不作为 Mod 写错库存的证据；八只机械手显示同一种的问题仍需单独复测，尚未宣称修复。
