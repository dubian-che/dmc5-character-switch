# pre-0.0.3 · 嘲讽输入与返回检查点修复候选

内部构建 release-49-input-checkpoint；诊断工具 support-49.1。

- 开启手柄切人时，原生键盘动作处于按下状态则不屏蔽共享输入，也不派发手柄组合切人。
- 先按住锁定、再按嘲讽以及同时按下，不触发组合屏蔽；手柄切人需先按住挑衅，再新按下 LB/RB。
- 输入来源查询失败时保留原游戏输入，停用该次组合识别。
- 为原生 restartMissionCheckPoint 补齐角色身份保护，重载前后恢复当前关卡的原生角色，取消旧选择。
- 诊断增加原生角色查询、PlayingID、输入来源、屏蔽掩码与检查点保护错误，便于复测。
- 保留上一版完整安装、固定加载器更新、备份、逐文件校验与失败回滚。

安装前完全退出游戏，解压运行启动器并点击安装 / 更新。已有按键设置会保留。
键盘锁定与嘲讽仍使用游戏内键位；手柄组合必须按上述顺序操作。

重点实测：保持启用手柄切人，以键盘按住 Shift 后按 R，在地面和空中均验证；再用手柄先挑衅后 LB/RB 切人。
M3 从任务选择进入，切至但丁或维吉尔，返回检查点后验证原生尼禄正常出现并可继续切人。
这是候选修复，仍需对应远端环境实测。未宣称解决所有 3S 交互或原生崩溃。
